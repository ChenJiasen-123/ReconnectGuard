录制说明

  • 录像分两段：jiang-demo-a.cast（mock 与回执，25 秒）与 jiang-demo-b.cast（真机案例），由 work/render_cast.py 合成 jiang-demo.mp4。
  • 两段都是实验机上的真实会话，命令与输出未编辑；时间戳、run_id、事件编号都能在服务器 results/ 下对应到原始产物。
  • 第二段命令省略 sudo：录制会话本身已是 root。真机命令若在 root 会话里再套一层 sudo，lab 采集框架补丁时 git 会因框架仓库属主检查失败（exit 129），该条件下本轮会以 environment_error 结束。触发条件本次未查清，规避方式是直接以 root 运行。
